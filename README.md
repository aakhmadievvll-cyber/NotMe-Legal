# Game Night — Legal & Support

Public legal and support pages for **Game Night: Group Party Games** («Посиделки»), a free
offline pass-and-play party game for iPhone and iPad, with optional AI themes by
subscription (Посиделки Плюс / Game Night Plus) since version 1.2. Since version 1.3 the
subscription also opens the premium bundled packs; 15 packs, one for every kind of game,
stay free, so every game is playable for free. Version 1.6 adds three quiz games built on
public data; their sources and dataset licences are credited in the app and in the Terms.
Version 1.7 lets the subscription (and one free set per Apple Account) create questions
for those quiz games with AI; their numbers and popularity are labelled as the AI's estimate.
Version 1.8 adds anonymous usage statistics (PostHog, EU cloud in Frankfurt; an off switch in
Settings) and shows the Game Night Plus screen once by itself, on the second visit.

The games have no accounts and no ads, and they play offline. The only feature that needs the
internet is the optional AI generator (themes since 1.2, quiz questions since 1.7); since 1.8
the app also sends anonymous usage statistics to PostHog, which never contain names, typed
text or Apple identifiers. The privacy policy describes exactly what each of them sends and
keeps — these pages are not a generic template.
